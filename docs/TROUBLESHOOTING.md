# Troubleshooting

## 2026-01-20: RAG 검색 결과 무관한 공고 반환

### 문제
"python 5년차" 검색 시 카지노, 건설회사 등 무관한 공고 반환.

### 원인
1. LLM이 `skills: null` 반환 → 빈 키워드로 검색
2. `nomic-embed-text` 모델이 모든 입력에 동일 벡터 반환 (코사인 유사도 1.0)

### 해결
- `ParsedQuery`에 validator 추가: `null` → `[]`
- 임베딩 모델: `nomic-embed-text` → `mxbai-embed-large` (768 → 1024차원)

### 문제
프론트엔드에서 특정 페이지만 요청 불가.

## 2026-01-20: C# 키워드 검색 시 결과 없음

### 문제
URL의 `#`이 fragment로 해석됨.

### 해결
`urllib.parse.quote()`로 키워드 인코딩.

## 2026-01-22: 한글 쿼리 파싱 시 LLM 할루시네이션

### 문제
"파이썬" 검색 시 Java 공고 반환. LLM이 쿼리에 없는 스킬 추가.

### 원인
- llama3.2 3B 한국어 미지원
- 프롬프트에 스킬 목록 제공 시 모델이 전체 복사
- Python vs Java 임베딩 distance = 0.23 (threshold 0.25보다 낮음)

### 해결
- LLM: llama3.2 3B → Kanana 2.1B (한국어 특화)
- 화이트리스트 제거, Few-shot 예시 사용

## 2026-01-22: 크롤링 후 응답 지연

### 문제
DB 저장 시 각 job마다 임베딩 개별 생성 (53개 × 60ms = 3초+).
크롤링(5초) + 임베딩(3초) = 10초+ 지연.

### 해결
임베딩을 Celery 백그라운드 처리로 분리.
