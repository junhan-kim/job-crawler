# 시스템 아키텍처

## 개요

LLM 기반 채용 정보 검색 에이전트. 사용자가 자연어로 조건을 입력하면 여러 채용 사이트에서 맞춤형 공고를 찾아 분석해주는 서비스.

## 데이터 모델

```python
# 사용자 검색 조건
class SearchCondition:
    user_id: int
    role: str              # 직무 (백엔드, 프론트엔드 등)
    experience_years: int  # 경력 연차
    skills: list[str]      # 보유 스킬
    min_salary: int        # 최소 연봉
    locations: list[str]   # 희망 지역
    preferences: dict      # 추가 선호사항

# 채용 공고
class JobPosting:
    id: uuid
    source: str            # 출처 (사람인, 원티드 등)
    source_id: str         # 원본 ID
    title: str
    company: str
    description: str
    requirements: list[str]
    salary_range: tuple
    location: str
    posted_at: datetime
    expires_at: datetime
    embedding: vector      # pgvector 저장용

# 검색 결과
class SearchResult:
    job_posting: JobPosting
    relevance_score: float  # 적합도 점수
    match_reasons: list[str]  # 매칭 이유
    analysis: str           # LLM 분석 결과
```
